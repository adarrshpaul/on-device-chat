EdgeOperator AI Privacy Policy

Privacy Practices & Data Protection

Last updated: October 18, 2026 • Version 0.2.0
Zero Cloud Data Transmission (100% On-Device Operation) EdgeOperator AI is architected from the ground up as an on-device local operator. Prompts, page content, accessibility tree structures, and automated browsing macros are processed entirely inside your local Google Chrome browser and GPU. Zero personal data, browsing history, or keystrokes are transmitted to external servers.

1. Information We Do Not Collect

EdgeOperator AI does NOT collect, store, sell, or transmit:

  • Personally Identifiable Information (Name, email address, phone numbers, physical address).
  • Browsing history, session activity, or page visit history outside active user-invoked interactions.
  • Financial, credit card, or payment information.
  • Authentication credentials, passwords, or session cookies.
  • Biometric or health data.

2. How Local Permissions Are Used

Our Chrome WebExtension declares minimal permissions required strictly for on-device functionality:

  • activeTab: Used exclusively when the user interacts with the extension to inspect the active webpage's DOM structure, highlight interactive elements, and execute user-directed workflow clicks.
  • storage: Used exclusively to persist user-created workflow macros, UI dock layout choices, and on-device model settings within Chrome's local sandboxed storage.
  • scripting: Used to mount the isolated floating assistant UI container into webpages upon user interaction.
  • contextMenus: Used to provide an optional right-click shortcut ("Ask EdgeOperator") for selected text.

3. Local Machine Learning & Inference

All neural inference and heuristic reasoning models (including Chrome built-in Gemini Nano via the Prompt API, Transformers.js, and WebGPU/WebLLM runtimes) execute on the user's local hardware. Model weights and temporary activation tensors remain within the browser's memory sandbox.

4. Data Sharing & Third-Party Disclosure

We do not share, sell, lease, or monetize user data with any third parties, advertisers, or data brokers. There are no remote tracking pixels, third-party analytics scripts, or cloud telemetry pipelines embedded in EdgeOperator AI.

5. Compliance with Chrome Web Store Policies

EdgeOperator AI complies fully with the Chrome Web Store Developer Program Policies, including the Single Purpose Policy and User Data Privacy requirements.
