# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security and integrity of on-device browser execution very seriously.

If you discover a security vulnerability (such as a sandbox escape, DOM injection, prototype pollution, or data exfiltration flaw), please **do not open a public GitHub issue**.

Instead, please report the vulnerability privately:
1. Use GitHub's private vulnerability reporting feature on this repository under **Security → Report a vulnerability**.
2. Or email `adarrsh@paulcreates.online` with:
   - Description of the vulnerability
   - Steps to reproduce / proof-of-concept
   - Potential impact

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure and fix release.
