# State: Fault-Tolerant DOM Resolution & Strict Widget UI Isolation

1. **Host vs Widget Boundary Isolation**:
   - The agent widget and its internal controls (`Run Batch Judge`, `Escalate`, `Re-scan`) are strictly tagged with `data-g4-widget="true"`.
   - `isWidgetElement` excludes these components from page snapshots, DOM inferrers, text scans, and click/type executions, preventing circular self-interaction.
2. **Robust Selector Resolution (`smartQuerySelector`)**:
   - Native `document.querySelector` calls are wrapped in defensive handlers.
   - Automatically sanitizes and removes Tailwind bracketed utilities (e.g. `text-[10px]`) before querying.
   - Recovers from malformed LLM selectors via direct ID lookup, CSS escaping, and semantic text matching against host elements.
   - Never throws unhandled `DOMException: not a valid selector` crashes.
3. **Explicit Snapshot Selectors**:
   - `snapshot` actions emit clean, verified CSS selectors (`[selector: "#search-input"] <input> ...`) generated by `getCleanElementSelector`, eliminating the need for models to guess composite class selectors.
