# Fact: Engram Associative Recall & Universal Website Navigation Workaround

## Summary
The on-device chat widget now features an autonomous engram-based website navigation generator and associative recall engine, acting as a universal workaround for websites with missing, hidden, or inadequate navigation menus.

## Architectural Principles
1. **Engram Constellations**:
   - Rather than storing flat link arrays, the engine compiles sparse constellations of DOM nodes representing landmarks, action tools, 3D WebGL canvases, and content concepts.
2. **Associative Pattern Completion**:
   - Matches partial signals ("Carol", "3D shirt", "projects") to candidate nodes via exact title matching, token overlap, and on-device neural embeddings (MiniLM cosine similarity).
   - "The most ready neurons win": Highest-activation node is reactivated and surfaced.
3. **Bicameral Motor Execution**:
   - Cognitive recognition (System 1) directly activates host motor actions: smooth scroll into view, focus state, and DOM spotlight overlay (`#g4-agent-spotlight`).
4. **Universal Fallback HUD**:
   - When users land on an unindexed, single-page, or poorly designed site, the "Nav Hub" tab exposes 100% of discovered actionable landmarks, interactive tools, and 3D canvases for 1-click teleportation.
