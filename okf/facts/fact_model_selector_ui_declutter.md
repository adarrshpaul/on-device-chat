# Fact: EdgeOperator Header Model Selector Pill De-cluttering & Icon System

The EdgeOperator chat header model selector has been refactored into a fixed-size `shrink-0` pill with distinct Lucide icons per tier (`Zap`, `Sparkles`, `ScanSearch`, `Brain`, `Gem`) and concise names (`Reflex`, `Nano`, `MiniLM`, `SmolLM`, `Gemma 4`). Secondary window controls (Dock and Ghost Mode) are housed in the `•••` overflow menu, guaranteeing that the model pill is never crushed or truncated on narrow panel widths (380px).
